<h1><b>SQL_Data_Warehouse_Project</b></h1>
<h3>Overview</h3>
A SQL data warehousing project designed to clean and model raw source data.<br>
<b>Note: </b>This repository is created for practice and educational purposes as part of the Data with Baara course on Udemy.

<h3>Project Objective</h3>
Building a reliable data warehouse that transforms unorganized data in to anaylitics ready environment.

<h3>Specifications</h3>
<b>Data sources: </b>Import data from two source systems(ERP & CRM) provided by CSV files.<br>
<b>Data Quality: </b>Clean and revolve data quality issues prior to analysis.<br>
<b>Integration: </b>Combine both sources into a single, user friendly data model designed for analytical queries.
